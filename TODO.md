# KeyRC Feature Roadmap

## Functionality
- [ ] Hotkey to toggle visibility - e.g., `Super+K` to show/hide overlay
- [ ] Pause/Resume recording - Temporarily stop showing keystrokes
- [ ] Filter modes - Show only modifiers, only letters, exclude passwords

## Settings
- [ ] Window opacity slider - Adjust transparency
- [ ] Key display timeout - How long keys stay visible
- [ ] Max keys shown - Configurable 1-8 keys

## Advanced
- [ ] Combo detection - Show "Ctrl+C" as single combo instead of separate keys
